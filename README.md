# LabVision 🩺

**تفسیرگر آفلاین آزمایش‌های پزشکی** — یک ابزار سبک، دوزبانه (فارسی/انگلیسی) و **۱۰۰٪ آفلاین** برای درک نتایج آزمایش خون و ادرار، بدون نیاز به اینترنت، حساب کاربری، یا ارسال داده به هیچ سروری.

> ⚠️ **این ابزار جایگزین نظر پزشک نیست.** خروجی آن صرفاً جنبه اطلاعاتی و آموزشی دارد.

---

## ✨ ویژگی‌ها

- **کاملاً آفلاین** — هیچ درخواست شبکه‌ای، هیچ API، هیچ سرویس ابری. همه‌چیز در مرورگر خودتان اجرا می‌شود.
- **۲۳۵ آزمایش پزشکی** در دیتابیس محلی — از CBC و بیوشیمی پایه تا هورمون‌ها، سرولوژی، نشانگرهای توموری، انعقاد خون و ژنتیک.
- **دو نوع تفسیر:**
  - **کمّی** (عددی) — مثل `Hb: 13.5` → مقایسه با محدوده نرمال (بر اساس جنسیت در موارد لازم).
  - **کیفی** (مثبت/منفی) — مثل `HBsAg: Negative` → تشخیص کلیدواژه فارسی/انگلیسی.
- **دوزبانه کامل** — رابط کاربری، نام آزمایش‌ها و توضیحات، هم فارسی هم انگلیسی.
- **تم روشن/تاریک** با پالت رنگی الهام‌گرفته از محیط بالینی.
- **چاپ / خروجی PDF** — خروجی به‌صورت جدول فشرده، شبیه برگه آزمایش واقعی، آماده چاپ یا ذخیره PDF از طریق دیالوگ چاپ مرورگر.
- بدون هیچ وابستگی خارجی (بدون npm build, بدون framework) — فقط HTML/CSS/JS خالص.

## 📝 نحوه استفاده

هر آزمایش را در یک خط جدید، با فرمت `نام آزمایش: مقدار` وارد کنید:

```
Hb: 13.5
Platelet: 250
TSH: 2.1
Glucose: 95
HBsAg: Negative
LDL: 145
```

- نام آزمایش می‌تواند فارسی یا انگلیسی، کامل یا مخفف باشد (مثلاً `Hb`، `Hemoglobin`، یا `هموگلوبین` همگی شناسایی می‌شوند).
- جداکننده نام و مقدار می‌تواند `:` یا `-` باشد.
- جنسیت را از بالای فرم انتخاب کنید — چون رنج نرمال بسیاری از آزمایش‌ها (هموگلوبین، کراتینین، آهن، هورمون‌ها و...) بین مرد/زن فرق دارد.
- روی «تحلیل نتایج» بزنید تا جدول نتیجه ساخته شود. برای موارد غیرطبیعی یا شناسایی‌نشده، توضیح در بخش «یادداشت‌های بالینی» زیر جدول می‌آید.

## ➕ افزودن آزمایش جدید

هر رکورد در `database.js` یکی از دو ساختار زیر را دارد:

**آزمایش کمّی (عددی):**
```js
test_key: {
    name: { fa: "نام فارسی", en: "English Name" },
    aliases: ["مخفف1", "alias2"],
    unit: "mg/dL",
    range: { all: { min: 0, max: 100 } }, // یا { male: {...}, female: {...} }
    interpretation: {
        low:    { fa: "...", en: "..." },
        normal: { fa: "...", en: "..." },
        high:   { fa: "...", en: "..." }
    }
}
```

**آزمایش کیفی (مثبت/منفی):**
```js
test_key: {
    type: "qualitative",
    name: { fa: "نام فارسی", en: "English Name" },
    aliases: ["alias"],
    negative: { label: {fa,en}, resultStatus: "normal", interpretation: {fa,en} },
    positive: { label: {fa,en}, resultStatus: "high",   interpretation: {fa,en} }
}
```

کافیست یک شیء جدید با همین ساختار به انتهای `labData` در `database.js` اضافه کنید — نیازی به تغییر `script.js` نیست.
